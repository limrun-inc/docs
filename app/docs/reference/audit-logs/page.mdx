# Audit logs

Organization admins can review their organization's archived activity in the Limrun console. Members, viewers, API keys, and instance tokens cannot access audit logs.

## Search activity

Select your organization in the [console](https://console.limrun.com), then open **Audit logs** under Account. Choose a start and end time up to 7 days apart and select **Search**. Times use your browser's local timezone.

You can filter by action, actor ID, resource ID, and outcome. Text filters match exact values. Results show the matching total and the current record range, newest first. Choose 25, 50, 100, or 200 under **Rows per page**. The default is 50. Use **Next** and **Previous** to browse, and **Details** to inspect an event's identifiers, source, HTTP status, duration, and available metadata.

Loaded pages stay available during the search, and the console loads the next page ahead of time. Returning to a loaded page does not run another search.

**Refresh** clears cached pages and repeats the current search window from the first page. To include activity after its end time, update **To** and search again. Changing organizations clears the previous organization's search.

## Read the results

Recent events may take a few minutes to appear. An empty result means no archived events matched the search; it does not prove an action never happened. Capture is best effort, and activity can be missing. Late arrivals can change results between pages.

Instance creation and readiness are separate events. A download grant records permission to download, not proof that a transfer completed. A successful billing request does not establish payment settlement.

If browsing is unavailable, the console displays an error rather than an empty result. Retry a busy search shortly. For a timeout, try a shorter window or more specific filters.

## Backend endpoint

The console uses `GET /organizations/{organizationId}/audit_logs` with the signed-in admin's session. This endpoint does not accept an API key as a substitute for organization admin membership.

| Parameter | Meaning |
| --- | --- |
| `start`, `end` | Required timestamps with timezone offsets. Start is inclusive and end is exclusive; the range cannot exceed 7 days. |
| `action`, `actorId`, `resourceId` | Optional exact text matches. |
| `outcome` | Optional `success`, `accepted`, `denied`, `failure`, or `unknown`. |
| `limit` | Optional page size from 1 to 200, default 50. |
| `cursor` | The previous response's `nextCursor`, used with the same organization, filters, and page size. |

The response contains an `events` array, a `total` matching count after deduplication and before pagination, and an optional `nextCursor`. The count may change as late events arrive. It does not provide a fixed snapshot across pages.
