# Audit logs

Organization admins can review their organization's events in **Audit logs** in the [Limrun console](https://console.limrun.com/audit-logs). Members and viewers cannot access this page.

Choose a start and end time, then click **Search**. Each search covers up to seven days. Times use your browser's local time zone. Recent events may take a few minutes to appear; click **Refresh** to reload the results.

## Actors and actions

The **Actor** column identifies who performed the action:

| Actor | What it means |
| --- | --- |
| Member email | A current member of your organization. |
| API-key name | An API key belonging to your organization. Keys without a name display as **API key**. |
| Limrun system | An automatic action, such as an instance becoming ready. |
| Instance | An action performed by a running instance. |
| Identity provider, OAuth application, or CLI session | Activity from that authentication flow. |
| Actor unavailable | The actor cannot be resolved, for example after a member leaves or an API key is deleted. |

Member emails and API-key names reflect their current values. Changing an email or renaming a key updates the label shown on older events too.

Actions use names such as **Create iOS instance**, **Create API key**, and **Instance ready**. **Details** shows the event ID and any available actor ID, resource ID, HTTP status, and duration.

## Filtering and pagination

Filter by outcome, action, actor ID, or resource ID. Text filters match exact values. Copy an action name from the table or an actor or resource ID from **Details**. Actor IDs are available for resolved organization members and API keys.

The results show the total matching event count. Use **Rows per page** to choose 50, 100, or 200 events, and **Previous** or **Next** to move through them.

For integrations using the audit-log endpoint, `actor` contains the display label and `action` contains the customer-facing action name. Both new action names and legacy exact action names work with the `action` filter. Optional fields can be absent when they do not apply or the identity is unavailable.
